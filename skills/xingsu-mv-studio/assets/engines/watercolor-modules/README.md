# 桌面工程可复用模块来源

本目录整理水彩工程模块。像素《小酒窝》模块另见 `../pixel-modules/小酒窝/README.md`。所有来源均为用户提供的原工程包；仅分发被技能和参考资料引用的代码及其本地依赖，不分发歌曲素材或渲染结果。

| 来源工程 | 直引文件与用途 |
|---|---|
| 《Rolling小苹果串烧》 | `Rolling小苹果串烧/render.py`：撕边纸条歌词及按旋律逐词写出，用于用户自备或占位文本。<br>`Rolling小苹果串烧/make_lyrics.py`：主行/副行的中文字符与英文词音节时间结构；所有歌词已换同长度占位文本。 |
| 《99》 | `99/render.py`：权威版 Renderer 入口、快歌片名时序、主行卡拉 OK 与转场。<br>`99/story1.py`：撕日历 A1 开场及前半段逐拍镜头。 |
| 《东西》 | `东西/dx.py`：杂货铺、指南针、竹蜻蜓、秋千、天平与旅行道具。<br>`东西/render.py`：慢歌片名淡入淡出分支。 |
| 《我好想你》 | `我好想你/wo.py`：镜像房间、铁盒、无手钢笔跟笔尖、逐笔便笺与分屏。<br>`我好想你/story_a.py`：慢歌 A1 写便笺开场、回忆与前半段镜头。<br>`我好想你/opening.py`：A1 器物旁的署名和歌手叠层。<br>`我好想你/storyboard.py`：按秒组织的慢歌分镜结构，主副歌标签已改为占位。 |
| 《苦咖啡·唯一》 | `苦咖啡·唯一/render.py`：带参数的主、副行卡拉 OK（backing=True），用于双层人声。<br>`苦咖啡·唯一/beatstrip_lean.py`：按拍顺序抽帧的低内存核查工具。<br>`苦咖啡·唯一/kf.py`：咖啡车、拉花、手冲壶、黑板 A 字牌、粉笔片名、场记板与立麦。 |
| 《罗生门》 | `罗生门/render.py`：竖屏歌词条、最大宽度限制、自动缩字与折行。<br>`罗生门/couple.py`：校园男女主水彩版：多视图、动作、眨眼、泪水与服装。<br>`罗生门/lsm.py`：天气小黑板、房间、聊天页、锁屏、片名门与开伞。<br>`罗生门/lsm2.py`：雨街、列车、车票、购票与手机通知界面。<br>`罗生门/lsm3.py`：路人、小摊、亮窗、晾衣、车辆、猫、蒸汽与稠密城市布景。 |
| 《偷偷拍下你的样子》 | `偷偷拍下你的样子/tp.py`：相机 App 取景框、拍立得、相机闪光、公园、撕页日历等道具。<br>`偷偷拍下你的样子/story_b.py`：titleBanner 屏幕层片名、titleTag 界面内标签与后半段镜头。<br>`偷偷拍下你的样子/beatstrip960.py`：带分镜事件表头的 960 宽逐拍帧条。 |
| 《你瞒我瞒》 | `你瞒我瞒/nm.py`：openingTitle 牛皮纸片名卡、档案袋、放大镜、餐厅、沙发、房间与纸箱。<br>`你瞒我瞒/cover.py`：3:4 和 4:3 标题关键帧封面绘制。<br>`你瞒我瞒/beatstrip.py`：支持 --even --cols 2 的体感拍帧条。 |
| 《可不可以给我你的微信》 | `可不可以给我你的微信/wx.py`：虚构聊天软件、二维码、咖啡店、诊室、病房、街景及长柄放大镜。<br>`可不可以给我你的微信/opening.py`：界面左侧片名标签和署名。<br>`可不可以给我你的微信/splice.py`：旧作只改开头时的无损拼接与包哈希核对。 |
| 《病变》 | `病变/bbset.py`：无窗卧室与生活布景零件：串灯、日历、钟、床头柜、浴帘和杂物。 |

| 《东京不太热》 | `东京不太热/tk.py`：提灯街道、贩卖机、铁塔、行人灯、温度计、保险箱和聊天草稿。<br>`东京不太热/build_data.py`：两段速度拼接拍表与逐字时间修正示例，注释歌词已占位。 |
| 《幻昼短发女孩罗生门串烧》 | `幻昼短发女孩罗生门串烧/mz.py`：齐耳波波头、茉莉花角色包装 herM() 与暖帘等道具。<br>`幻昼短发女孩罗生门串烧/story2.py`：hisRoom 无窗卧室的组合实现与夜间镜头。 |

每个子目录的 `README.md` 逐一列出直引入口和依赖文件。复制后仍需准备工程数据、字体和输出目录，不能把这些目录当成完整可运行的歌曲项目。
