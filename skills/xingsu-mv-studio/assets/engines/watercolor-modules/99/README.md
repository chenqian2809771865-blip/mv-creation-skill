# 《99》可复用代码模块

来源：用户提供的《99》桌面 MV 工程包。只收录技能正文、参考资料与 01–08 细则实际引用的代码及必要的本地导入依赖。

这些文件是供移植和阅读的模块，不是可直接执行的完整歌曲工程。原音频、歌词、拍表、笔顺数据、成片图片、视频、模型和渲染分片均未复制。创建自己的工程后，需从用户自备素材生成拍表、占位或获授权歌词数据，下载所需字体，并按目标画幅与分镜调整配置。

署名由 `mv_config.py` 读取技能根目录 `config.json` 的 `SIGNATURE`，也支持环境变量 `MV_SIGNATURE`。拷贝到独立工程时，请将配置文件放在该工程的上级目录或设置环境变量；模板署名未配置时会要求用户设置。

## 直接引用的文件

- `render.py`：权威版 Renderer 入口、快歌片名时序、主行卡拉 OK 与转场。
- `story1.py`：撕日历 A1 开场及前半段逐拍镜头。

其余 `.py` 文件是这些入口的本地导入依赖；保留各工程的版本，不覆盖随附通用引擎。代码中的真实歌词已替换为同长度占位文本，歌词示例的时间与音节数组保持原结构。
