# 开场选项

前奏安静时，也不要用静止标题慢慢铺十几秒。可选的做法：

- 回忆快闪，约 1.5–2 秒一切
- 主角入场
- 画内标题器物（A 式）
- 界面序幕（B/C 式）

无论哪种，都在第一个重拍或第一句人声处切入正片。

## A1 · 画内标题器物（来源：《情歌》《晨间新闻》《出现又离开》像素 MV）

歌名能落到故事世界里某个会显示文字的东西上时用，例如播放器的“正在播放”、电视或电台节目、车站翻牌、招牌、信封、车票。不另做标题卡。器物要贴合歌意，画在同一网格上，带自己的质感。

1. **第一秒就是器物**，第一个音符前后完成第一下动作。
   - 播放卡：抢在第一个音符前约 0.6 秒弹出，歌名逐字打出（每字 2–3 帧），落在音符上。
   - 翻牌：每 3 帧乱翻一次，每拍锁定一格，最后一格落在小节首拍。最后一格锁定后，特写至少再停两拍，让观众看清完整标题，不要在锁定那一帧切走。
   - 节目类：台标常驻角落，主播的第一条字幕就是开场白。
2. **器物用自己的动作踩拍**：走秒、音量条、♥ 点亮、口型、LIVE 红点、跑马灯、翻牌。故事前提写在器物上的字里（地点时间牌、越来越急的新闻标题、“到站/离开”），不加旁白。
3. **从器物进入故事世界**：动作起点在小节首拍或拍上，可提前 3–5 帧；在第一句人声前至少留 1 小节做完。按歌速选：
   - 慢歌，下摇一镜到底：器物挂在高画布的夜空里，约 3 拍下摇到街景，主角走进来、头顶冒 ♪；乐队进来前的空拍硬切近一级。
   - 快歌，留在器物里换台：远景和特写每 1.33 秒交替，标题一条比一条急；再快切换台，每次插 1–2 帧雪花、台号递增、一台一个梗，越换越快。
   - 中速、双主角：锁定后切竖向分屏，左他右她，地点和天气形成对照，约 2 小节后切近一级。
4. 器物阶段主角不出场，切镜多少跟着歌速走。片尾可以用同一个器物回扣。
5. **招牌类器物要左右对称**：
   - 灯泡沿边等距、四角都有，上下行、左右列对齐；亮灯、熄灯、追光都从中轴向两侧展开。
   - 不用会被裁切的跑马灯，改成居中的静态字。
   - 字号按镜头缩放选，放不下就画成短横，不要压到别的字上。

## A1 变体 · 节目内容被现实推翻（来源：《晴天》管弦乐版，用户认可）

适用条件：歌名正好是器物会播的一句话，而且编曲一开头就是全奏（没有安静前奏可以做 B 式，也没有第一句人声可切）。实现见 `assets/engines/pixel-320-couple/code/shots_open.py`。

1. 先给关着的电视约 0.3 秒，弱起时开机；第一下全奏砸出预报卡（大字歌名＋图标＋跑马灯），屏下黑板写日期，交代时间。
2. 低音进来的那一下，画面一震、云盖住太阳、插 2 帧雪花。之后每拍锁一格：晴天 → 多云 → 大雨 → 暴雨；最后一格落在重击上，屏幕变红、预警横幅闪烁，房间的光一档档变暗。
3. 低音整段抽空的起点 = 停电：画面先 2 帧压成一条亮线，再 2 帧缩成白点，约 0.3 秒后熄灭；接 1 帧闪电白切进故事世界。低音回来时切暴风雨大全景，用重击时的闪电依次照亮他和她。
4. 第二次低音抽空 = 定格：整帧冰蓝，只留信物的红色；低音回来时解冻、冲向镜头，借镲的白闪切进正片。
5. 片尾来电，同一台电视重新亮起开头那条预报；最后一句歌词写在黑板上，然后关机熄灭。

## A1 变体 · 影院翻牌招牌（来源：《白兰花》）

适合慢歌、前奏约 4 小节的情况。实现见 `assets/engines/pixel-640/examples/bailanhua/shots_intro.py`，招牌本身在 `sh_street.py` 的 `marquee_overlay`。

1. 没有低音的铺垫段，灯泡从顶部正中向两侧一颗颗亮起。
2. 底鼓一进，招牌全亮；片名按拍逐字锁定，完整标题停两拍。
3. 下一小节退一级，露出钟楼；再一镜下摇到门口，主角拿着两张票在等人。
4. 切电影票特写，雨点打湿票面。
5. 第一句人声时，钟走到 00:00，招牌灯熄灭。
6. 片尾招牌上的字翻回空白。

## 界面序幕 B / C（来源：《玫瑰花的葬礼》《素颜》）

适用条件：前奏 8 秒以上，并且需要交代人物关系或前史。

做法：第一帧就进入手机、App 或游戏界面，用界面自己的语汇讲完前史（消息、日期分隔、已读/撤回、通知、进度条、数值）。标题卡只占 2–3 秒，嵌在前奏中段的强拍上。第一句人声起点切进正片。

B 式范例见 `assets/engines/pixel-320-couple/examples/bandao/`。另一个技能「心理学-聊天框科普」引用了这里的“B 式聊天序幕”，改名时要同步。

### B 式聊天长镜（前奏 15–25 秒，慢歌）

依次是：

1. 引爆冲突的一句，加“正在输入…”；之后约每半拍弹出一条。
2. ◀◀x8 回放：换成旧的主题色，按八分音符一屏屏往回滚，每屏一个关系节点。
3. 逐字打出挽回的话，显示已读，对方只回“…”；镜头缓推。
4. 2 帧白闪，切标题卡（配与歌名相关的粒子）。
5. 消息变成“撤回”，再打字又删光，淡出到黑。
6. 锁屏通知写出时间跨度（例如“她 · 100 周前”），按拍硬推两级；人声起点切进正片。

### C 式界面快切（前奏 8–12 秒，轻快或对唱）

6–7 个全屏界面，每个 0.7–4 秒，切在拍或半拍上，一镜一个梗。可用的梗：

- 锁屏通知被点开
- 修图 App 的滑杆逐档拉到 0，档与档之间插 1–2 帧故障
- 道具飘过
- 标题做成开关：弹入 → 划掉 → “OFF/ON”牌 → 正式标题
- 格斗游戏的 VS 属性卡，用来介绍男女主
- 年份折线图分叉

### B / C 通用

- 所有界面画在同一网格上，不加旁白；时间跨度交给 ◀◀x8、日期和通知时间来表达。片尾回扣开头的界面。
- 前奏短于 6 秒时，只取一两个梗，也可以只借用单个手法。
- 原曲前奏有对白或环境音时，用界面接住：语音“转文字”逐字跟随对白（时间取自分离人声的 ASR）；前奏全停的地方对应熄屏。
