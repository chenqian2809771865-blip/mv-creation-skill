# 角色库

用户指定的角色优先。选择规则写在 SKILL.md 的硬规则里，这里只放设定和实现要点。同一份角色定义贯穿全片；识别特征保持不变，故事、场景、季节服装每首重新设计。

## 像素校园男女主

像素校园男女主可选，按歌选角；首次用于示例《说好不哭》。实现见 `assets/engines/pixel-320-couple/code/chars.py`（已含书包 `bag=True` 和“？”表情）。

- **他**
  - 黑色短碎发（#2c2536，高光 #4b4060），锯齿刘海。
  - 藏青连帽卫衣（#3b5b98，暗 #2a4375，亮 #5a80c2），米白抽绳（#dcd6cc）。
  - 深色长裤（#343a52 / #252a3d），白球鞋（#e8e4de）。
  - 常背深棕吉他琴盒（#3a2b27，背带 #231b1c），雨天戴兜帽。
  - 性格：内敛的追梦音乐人。
- **她**
  - 棕色齐刘海波波头，长到下颌（#6b3d2b，高光 #94573a）。
  - 奶油色毛衣（#efe4cb / #cdbd9c）。
  - **红围巾**是标志色（#cc3b42 / #972a35），尾端垂在胸前。
  - 深紫灰短裙（#4d4560），深色裤袜（#3f3747），棕短靴（#7b4a32）。
  - 性格：温柔，笑着放手。
- **共用配色**
  - 肤色：他 #f2c9a8 / #d9a083，她 #f6d0b2 / #dfa689。
  - 腮红 #f19a92，轮廓 #1d1828。
  - 信物：红色心形拨片（#e84a5f，带白色像素心）。
- **像素规格**（320×180 画布，最近邻 ×8）
  - 小人约 32px：头 13×13、躯干 11、腿 9；视角 side/front/back。
  - 眼睛 1×2，约 3.7 秒眨一次；姿势 stand/walk/sit/floor。
  - 部件用暗一号描边，剪影外圈 #1d1828；按场景乘光照色，可加单侧轮廓光。
  - 近景半身：头宽约 45px，在同一网格上画。
- **换画风或画幅时**：按本项目规范调整像素密度，保留识别特征。非像素画风至少保留配色、发型、卫衣和红围巾。
- **48px 大头版**（约 2.3 头身，手持 phone/knees/guitar/sign/face/ear/eat）：《说好不哭》工程已被用户删除。需要时按上面的规格，在 `chars.py` 的基础上重画。

## Clawd 男女主（默认男女主，《小镇姑娘》《疑心病》《后来》《失眠》等）

用户说“默认男女主”指的就是这对，实现见 `assets/engines/watercolor-clawd/`。

- **他**：原色 Clawd（col #D97757 / dk #A84D33 / lt #F5B394）。
- **她**：同一造型换成粉色（#EE9AAE / #C0637B / #FBD0DA），头顶一朵白色小花（hat 'flower'）。花是她的识别物，换帽子时花和新帽子一起画。
- **调用**：`him(x, y, u, o)`、`her(x, y, u, o)`。Skia 版 `clawd(x, y, u, o)` 的选项传 dict，参数名和 p5 版一致（见 references/characters.md）。
- **戏服按歌另加**：
  - 《疑心病》她戴猎鹿侦探帽（花别在帽上）、拿放大镜，结尾把帽子扔掉。
  - 《后来》用围巾和校服区分现在与十七岁。
  - 《会不会》把小白花换成雏菊。
- **视图**：中近景和有情绪的镜头用正面或 q（3/4）视图，侧面只用在走路远景。侧面时脸缩成边上一只眼，看着像粉色盒子（用户原话：“人物表现形式不对”）。
- **室内用正面构图**：人坐在书桌后面对镜头，窗在身后，前景书桌挡住下半身，桌上物件画在人物之后。他的房间做成她房间的镜像（整体 `scale(-1,1)`）；镜像里的文字（日历等）要放在镜像之外画，否则会反字。
- **坐姿**：Clawd 宽 10u，长椅要放得下两人（宽 ≥ 2×10u 加间隙）。地面点取椅面 +2u，身体底边落在椅面上，腿垂在椅面前沿。绘制顺序：椅背 → 椅面 → 人物。不要用 noLegs 再贴腿，也不要让椅面横穿身体（`sets2.seat()` 已按此实现）。
- **不穿模**：
  - q 视图和正面时，两人中心距 ≥10.2u；侧面时 ≥6.2u。
  - 倾身旋转会让顶角多压进去 8u·sin(rot)。亲吻只让顶角相碰（亲脸颊）。
  - 骑车、搭肩这类必然重叠的动作，换成一样有年代感、又好画的画面（例如天台夕阳下一人一只耳机）。
- **手持道具**：画在世界坐标里，朝向写死。例如喷壶壶嘴朝下对准花盆、水从壶嘴流出；用 arm hook 的局部坐标，翻转后容易把壶嘴画成朝上。
- **夜里的雾玻璃**：用蓝灰雾（约 #B8C2E2→#8E98C6，不透明度约 0.46）。接近白色的雾会把整帧洗白。

## 小酒窝男女主（林俊杰的歌，《小酒窝》《白兰花》）

用户说“人物复用小酒窝”时用这对。

- **他**：灰底红竖纹格纹礼帽、格纹马甲、条纹领结。
- **她**：栗色齐刘海、长睫毛、小酒窝、红蝴蝶结、粉色背带裙。
- **320 版**：在 `assets/engines/pixel-modules/小酒窝/`。
- **640 版**：`assets/engines/pixel-640/examples/bailanhua/chibi.py`。SB 矢量部件；她有三种造型：`style='memory'` 长发、红蝴蝶结、粉背带裙，`'cut'` 波波头加蝴蝶结，`'now'` 波波头、深红唇、梅色外套。`over=` 换色可以做路人。同目录还有午夜上海街、弄堂立面、几处室内场景。
