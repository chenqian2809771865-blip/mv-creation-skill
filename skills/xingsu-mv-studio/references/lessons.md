# 经验暂存

新学到的做法、坑和用户反馈先记在这里，不直接写进 SKILL.md。这样主文件不会随项目越堆越长，个例也不会被当成通则。

## 规则

- **怎么记**：一条一行，写清楚日期、歌名、结论，必要时加用户原话。要能直接照做，比如写“人物过小，主体占画面高度至少 1/3”，不要写“还不够好”。
- **升格条件**：同一条在两首以上的歌里都成立，或者用户明确说“以后都这样”，才升格。
- **升格去向**：
  - 通用规则进 SKILL.md。
  - 角色相关进 references/cast.md。
  - 开场手法进 references/openings.md。
  - 实现细节进 references/styles.md 或对应引擎的 README。
- **升格后**：从这里删掉。
- **什么时候动技能文件**：只在用户要求把经验固化进技能时才改，平时记在工程自己的 README 里，交付时一并提出。
