# 随附引擎与可复用模块

本目录保存三套起点引擎，以及从原工程按引用收录的代码模块。公开示例已换成占位文字，拍点与逐字时间只演示数据格式。

换歌时复制对应目录为独立工程，重写分镜、镜头与本歌道具并重新对齐音频。制作与交付以技能根 `SKILL.md` 和 `references/notes/08_作废更正.md` 为准：2K 母版与 720p 预览统一走 `scripts/mvrun.py`，像素引擎需先按技能入口加入适配器。权威片名/卡拉 OK 分支及可复用道具在 `assets/engines/watercolor-modules/README.md`；不要把历史说明中的旧编码脚本当作当前入口。

| 目录 | 画风 / 角色 | 逻辑画布 → 输出 | 起点工程 | 速度（云端 2 核实测） |
|---|---|---|---|---|
| `watercolor-clawd/` | Skia 水彩 + 沸腾墨线；Clawd 男女主、人类 Q 版阿屿 | 1920×1080 → `MV_OUT`（母版 2K） | 《失眠》整套（节拍卡点 + 卡拉 OK） | 960×540 约 0.1–0.3 秒/帧；2K 约 0.3；4K 约 1.4 |
| `pixel-640/` | 高清像素（抖音画质友好）；黑礼帽男、黄伞女；小酒窝男女主 640 版 | 640×360 → 最近邻 ×4 = 2K | 《下雨了》整套＋ `examples/bailanhua/`《白兰花》（午夜上海街、影院翻牌招牌开场） | 640×360 约 0.1–0.4 秒/帧 |
| `pixel-320-couple/` | 320 像素；像素校园男女主 | 320×180 → ×8 = 2K | 《晴天》整套（A1 天气预报开场、画内歌词）＋ `examples/bandao/`《半岛铁盒》（B 式聊天/语音转文字/锁屏开场） | 2K 约 0.03–0.1 秒/帧 |

共同约定：帧只由 t 决定，随机用固定种子；按帧末时刻采样；成片和预览一律用 BT.709 转换并打色彩标记、锁 High@5.1（本目录里各自的编码脚本已按此修正，母版统一走 `scripts/mvrun.py --profile master` 或 `scripts/master.py`）。

除随附快乐体外，其余字体按需下载：`python3 scripts/get_fonts.py <目录> --unifont / --fp12 / --wenkai`，各引擎放哪见该脚本说明。水彩引擎的 ZCOOL 快乐体已随包。

《说好不哭》48px 大头版原工程已删除；随附 320 校园男女主以 `pixel-320-couple/code/chars.py` 为准。小酒窝 320 版见技能根 `assets/engines/pixel-modules/小酒窝/`，640 版以 `pixel-640/examples/bailanhua/chibi.py` 为准。
