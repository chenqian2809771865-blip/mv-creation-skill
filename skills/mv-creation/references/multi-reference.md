# 多参考综合与样片

用户提供多款 MV 参考，或希望提炼某种像素风音乐视频的视觉和节奏时阅读。单片拆解与音乐版本对齐见 [拆参考视频](references/reference-video.md)，目标歌曲的时间基准见 [音乐与字幕](references/music-lyrics.md)。参考数量可变，三款是常见情况。

## 从参考到本次方向

- 给参考编号，记录视频、对应音频、歌词、来源区间和用户喜欢的片段；同时标记本次目标歌曲。缺少独立参考音频时可提取视频音轨，缺少歌词时标记待核对，不阻塞画面分析。
- 先分别看代表帧与连续运动段，再比较三款的共同规律和差异。不要只凭封面、文件名或前几个镜头判断整片。
- 用户指定主参考和借鉴点时照做。例如以 A 的像素密度、角色比例为主，取 B 的背景层次和 C 的乐句切镜。未指定时先完成比较，提出一个连贯方向并说明选择；明显冲突且影响样片时再问一个具体问题。无须机械平均混合三套风格。
- 将看得到的事实、暂不确定的推断与本项目的制作选择分开。像素格、调色板、动作帧数受缩放、插帧和压缩影响，不能仅凭估计宣称恢复了原始参数；不凭播放量推断爆款原因。

## 产出可执行的项目资料

文件保存在本次视频工程，名称可沿用已有约定。建议保留以下三类资料；已有文件就更新，不另建重复版本。

| 资料 | 最低有效内容 |
|---|---|
| `reference-analysis.md` | 每款参考的代表帧位置、带时间码的镜头表，以及画面/动作/音乐触发点；标出观察证据、推断和不确定项。最后比较共性、差异与本次借鉴点。 |
| `visual-spec.md` 或 `style-spec.json` | 本次选定的画幅、逻辑像素网格与放大方式、角色识别特征与比例、色彩光照、背景层次、轮廓和纹理、动作节奏、镜头/转场与歌词排版。记录各项参考依据、允许的例外和样片反馈。 |
| `storyboard.csv` 或 `storyboard.json` | 目标歌曲的开始/结束秒、音乐段落/歌词、景别与构图、角色状态/关键动作、背景运动、镜头/转场、音乐触发点、所需素材和实现方式。 |

规范写到足以改变绘图和动画参数。例如将“怀旧、细腻、有电影感”进一步落实为所选像素网格、暖光/冷影、主体占比、前后景运动关系和动作节奏；数值由参考与样片决定，不预设统一色数或帧数。

优先明确容易发生分歧的选择：

- 人物沿用用户现有角色、参考角色还是新角色；保留哪些发型、服装、比例与识别点。
- 像素网格是全片一致还是有参考支持的分层处理；文字是否采用同一网格，缩放如何保持清晰。
- 背景以静景、局部循环、分层视差还是连续运动为主；镜头变化由什么音乐事件触发。
- 动作更新节奏与最终导出帧率分别如何安排；低帧动作可以在高帧率成片中保持，不把导出 fps 当作动作帧数。
- 字幕的字体、字号、位置、换行与显色方式，及其与角色表演的避让关系。

用户指定的方向和已认可的样片是制作依据。主技能中的默认横屏、开场手法（references/openings.md）及旧角色的实现尺寸（references/cast.md）只是后备选择。每个主要镜头应能指出遵循了哪些项目规范，分析资料才真正进入制作。

## 映射到目标歌曲

为新歌独立核对音乐段落、歌词和拍点，把参考中的关系转成新歌的镜头安排。例如“乐句结束后留出一拍，再在副歌起点切近景”，实际时间取自目标音频。参考的秒数、BPM 和歌词时间不能直接作为新歌时间轴。

拍点用 `beat_track.py` 实测（见 references/beat-sync.md），歌词时间用 `align_lyrics.py` 按实际演唱校准（见 references/music-lyrics.md）。变速、自由速度、切分、弱起或重复副歌仍要结合实际音频逐段核对；音量峰值不自动等于小节重拍。

## 先用样片验证

约 15–20 秒通常足以检验一组关键选择，用户指定范围时按其要求。挑最能代表作品难点的乐句，覆盖需要验证的角色动作、背景运动、景别/转场和歌词；纯氛围或无字幕任务无需为凑项目添加内容。

1. 用本次规范完成真实渲染并配上目标音乐。联系表用于看构图和一致性，连续播放用于看动作、转场和音画关系；只有静帧不能证明动画已达标。
2. 对照用户选定参考的相近镜头类型，在相近观看尺寸下比较。检查像素颗粒、色彩光照、角色比例、运动层次、镜头呼吸和歌词可读性；用户要求复现某种手法时，重点验收该手法。
3. 差异写成可操作的修改，如“人物过小，增加主体占比”“雨点变化过密，减少粒子并降低更新频率”，不要只记录“还不像”。保留对比帧或短预览作为依据。
4. 将用户反馈或内部检查结果同时更新到规范、分镜和实现，再扩展全片。用户只要求样片或明确要求看过再继续时，在该边界交付；已授权连续完成时按原授权推进。

## 与像素资产工具结合

`mv-creation` 负责分镜、时间轴、字幕和成片。外部像素工具可按需负责角色、道具、背景或动作帧；只使用当前可用、与任务匹配的能力。具体工具未安装时，先用现有 PIL/numpy 或已有工程实现，不把新安装变成每个项目的前提。

外部素材进入工程前检查逻辑网格、色板/光照、角色比例、透明背景、锚点和帧时长；精灵图集要明确每格尺寸、顺序与动画时长。保留可编辑源文件，复用同一套角色与背景定义，避免各镜头分别生成后风格漂移。

参考分析、规范和样片版本保留在项目中。后续同风格作品可引用已验证的规范与资产，并单独设计新歌分镜；只有用户要求把经验固化进技能时才修改技能文件，避免把本次故事、整段歌词或大量抽帧塞进通用技能。
