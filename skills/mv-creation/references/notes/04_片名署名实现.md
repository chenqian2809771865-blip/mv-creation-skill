# 片名与署名：实现细节（原硬规则 8 的做法部分）

> 这是 mv-creation 技能的分层资料，原样从技能主文件移来（2026-11-04）。文中「x 节」「硬规则 N」指主文件同名小节；原 3.1 节在 references/notes/02_慢歌剧情.md，4.3 节在 references/notes/03_写镜头代码.md，4.6 节在 references/notes/05_竖屏2x3.md。维护时在当前仓库中更新对应文件，由版本控制记录改动。

规则本身（落点表、字号、样式、位置、进退场时间）在主文件硬规则 8；这里是例子、实测值和代码。

- A1 与“第一拍”：“第一拍”在无前奏的歌里就是第一句人声（落在弱起拍、或 B[0] 在片头之前时，`K_TITLE` 取 k1）。A1 例：《100》《我好想你》按笔顺一笔笔写出片名（笔尖停在笔画末端直到下一笔，最后一笔落小节首拍；《我好想你》`wo.writeTip()` 让无手钢笔跟着笔尖，片名字先用 `build_strokes.py` 加进 strokes.json）；《超级棒棒糖》灯泡招牌 k0 整块点亮，屏幕层只叠歌手名 + 署名，放在招牌上方的天空。A1 的器物镜头在片名完整后至少再停约 1.2 秒。器物上另写了字、片名走屏幕层片名卡时（《你瞒我瞒》档案袋盖「绝密」），片名卡用和器物同一套材质，器物的落章挪到下一拍；片名弹入那一拍不放别的大事件。
- 实际值：快歌约 1.4–1.7 秒（《宠坏》150 露 1.6，《失眠》127 弱起露 1.4），慢歌约 1.4–3.6 秒（《你瞒我瞒》体感 76 露 3.2，《于是》67 露 3.6，《东西》84 露 1.43）。写死成「0–2 秒」会越过小节线（2026-11-01 三部旧作已改）。
- 不按拍网格切镜的现场录音（3.1 节），前奏各段内部速度稳，照样用前奏的小节线算 TA/TO。
- 水彩在 `render.py` 里算（`from common import B, isDown`；体感拍歌的 `isDown` 按第 2 节定相位），`Renderer.frame` 里卡拉 OK 之后叠加。像素引擎用各自拍表里的小节首拍（640 的 `timing.json` 里是 `downbeats`）照同样规则算：
```python
K_TITLE = 0                                                    # 落点拍（B 的拍号 k），见落点表
TA = B[K_TITLE]
downs = [B[k] for k in range(K_TITLE + 1, len(B)) if isDown(k)]   # 落点之后的小节线
BAR = downs[1] - downs[0]
SLOW = BAR > 2.4                                               # 体感慢于 100 BPM 算慢歌
TO = next(d for d in downs if d - TA >= 1.2)                   # 在这条小节线之前淡完
if TO - TA > 4:                                                # 很慢或弱起：提前半个小节
    TO -= BAR / 2
FO = .4 if SLOW else .22
# A1：TO 改成器物镜头开始下摇或切走的时刻（仍至少露 1.2 秒）
# Renderer.frame 里：
k_in = ease(seg(t, TA - .1, TA + .3)) if SLOW else backOut(clamp((t - (TA - .04)) / .22))
k_out = 1 - ease(seg(t, TO - FO, TO))
```
- 4.1 节的 render.py 片名块实际只有快歌弹入，慢歌分支拷《东西》包 `assets/engines/watercolor-modules/东西/render.py`。慢歌的片名函数若用 k_in 做缩放（`nm.openingTitle`、`opening.titleCard` 都是 `scale(k)`），把淡入也交给图层透明度：`openingTitle(1.0, ease(seg(t, TA - .1, TA + .3)) * (1 - ease(seg(t, TO - FO, TO))))`，否则 0.4 秒“淡入”会变成从 0 放大。
- 只补或改署名时，`--redo` 覆盖署名跨到的镜头即可（《你瞒我瞒》`--redo 0.05 2.4` 重渲 S01、S02）。成片从母版抽署名期间的帧复看：在、看得清、没压脸。

## 从主文件硬规则 8 移来的细节（2026-11-04 精简主文件时移入）
- 落点拍带白闪时，等白闪结束那一帧再进。像素：快歌整格弹入、慢歌逐字出现，退场在小节线那一帧切掉。
- 跨切镜后下一镜在署名位置有脸或界面：在切镜处一起淡出，但至少露 1.2 秒；甩镜、快推把脸带过时在运动开始前淡完（`TO = min(TO, max(TA + 1.2, 甩镜开始))`）。
- 界面占满全屏时，小标签放进界面里没控件的一角；和第一小节的大字、大梗、顶部旁白错开位置。
- 样式：水彩署名是文楷白字、墨色描边、画出来的黄星星、约 0.92 不透明、斜 −0.06（快乐体没有 ★）；像素署名不透明、1 逻辑像素深色描边，320 版放片名下方单独一行。
