# 写镜头代码：完整细则（原 4.3 节）

> 这是 mv-creation 技能的分层资料，原样从技能主文件移来（2026-11-04）。文中「x 节」「硬规则 N」指主文件同名小节；原 3.1 节在 references/notes/02_慢歌剧情.md，4.3 节在 references/notes/03_写镜头代码.md，4.6 节在 references/notes/05_竖屏2x3.md。维护时在当前仓库中更新对应文件，由版本控制记录改动。


**读代码**
- 写之前先看所用引擎 README 和工程 README 里记下的坑。常犯的几样：拍号和秒混用（`es(t, 128, 128.8)` 里的小数拍号要先用 `kt()` 换成秒，references/beat-sync.md）；她换帽子时小花和新帽子一起画（references/cast.md）；缺字见下面“表情与字体”；分屏坐标见下一条。
- 长片上下文容易占满（《倒带》实测）：复用道具库时可以只 grep 函数签名，但带单位、坐标或拍号参数的函数要读函数体或文档字符串。踩过的单位：`inkLine(pts, sw)` 的 sw 是笔刷倍数（'ink' 基准约 5 px，按像素传会画成粗团，要精确宽度用 skia 描边路径）；`sets.board(x, y, w, h)` 以中心为原点；`ch.batteryPct` 的 s 是像素（约 100），最小只显示 1%（0% 用《去北极忘记你》`bj.battery2`）；`nm.plushHim(x, y, s)` 的 s 是 u；`sets2.wallCalendar` 写死「10月」（nm.livingBack / hisRoomBack 都调它），按当月替换引用（《100》`hb.calendar11`）。
- import：镜头模块之间只按名字 import（`from story2 import s07, …`），`import *` 会把 eng 的同名函数（ring 等）盖回去，报参数个数错；`import *` 也带不出下划线开头的名字（《东西》`dx._pa` 要单独 import）。`sets_huibuhui.py` 一 import 就把 `clawd.flowerAt` 全局换成雏菊，要用里面的函数就拷进本歌模块。
- 水彩引擎的 `cam(t, cx, cy, z)` 是把 (cx, cy) 放到画面中心。分屏用《我好想你》`splitScreen(t, left, right)`：每半边 clip 后平移 ∓W/4，各自的 cam 中心对准主体世界坐标就居中（不平移、各用半边中心会把两人挤到中线上，《你瞒我瞒》）；书桌这类宽场景 z≈1.0，人物离分屏线太近会被切掉。cy 小于 540 会把地面往下推：每镜核一下 `540 + (脚 y − cy)·z < 940`，否则脚落进歌词条。
- 大宽度场景（海、天空）配平移镜头时，把天空和海锁在画面上跟着镜头走，否则会露出边缘。整屏渐变背景写 `gradRect(-400, -400, W + 800, 1900, …)`：顺手写的 1300 只铺到 y=900，没有地面的场景（太空、天空）底部会露出一条纸色硬边（《99》S09）。俯拍桌面 `woodTop` 只铺到 −300..W+300，拉远到 z≈1 或镜头中心偏离时先铺一块比画布大得多的底色（《我好想你》）。
- 把整帧画面缩进一个小屏（手机屏、电视里的取景框）时，缩放前先 `clipRRect` 到目标屏幕矩形：场景底色都画到画布外，缩小后会铺满屏幕外、把真实场景盖住。

**摆位与手持道具**
- 不穿模：q 视图和正面时两人中心距 ≥10.2u（references/cast.md）。侦探帽的帽檐每侧超出身体约 1u（按 `clawd.py` 的帽子尺寸算），两人都戴就 ≥12u；波波头（两侧各宽约 0.75u）≥11u；老年白发（约 1u）≥12.5u，并排坐、拥抱也一样。伸手递东西时再加上手臂伸出的长度（先出一帧量）。递给对方的道具最后画，离对方帽檐留出一个道具宽。u≈26 两人并坐时中间只剩约 20 px：卡片举在递出者外侧那只手上（卡片角压住手点），落拍飞到对方腿上（嘴以下），不举在两人头顶之间（《99》）。
- 手持道具（相机、伞、雏菊、餐罩、举牌、杯子）一律用 `handXY` 取真实手端位置，再在世界坐标里按写死的朝向画（挂在 armR 局部坐标上，flip 后容易朝向画反）；左右两只手里挑离目标近的那只（q 视图、flip 后哪只手在前不直观；《我好想你》工程包的 `armToward(o, x, y, u, 目标x, 角度)` 两只手各试一次 handXY，返回 (o, side)）；q 视图 aR≈0.9 时手端正好在头侧（耳机罩、帽檐），道具像从那里长出来，长柄道具用 aR≈0.4 握在身体侧面（《东京不太热》）；`umbrellaAt` 的 (x, y) 是伞柄底端，直接放在手上。手端补一个和身体同色、带墨线的小圆点当“手”盖住杆底，第一眼才读得出“握着”（没画手点常被判成浮空）。手持长柄工具从手连到工具头，别在世界坐标里随手画斜杆（会穿脸）。
- `handXY` 不算 `rot`：拿道具的角色不转身体，用 dy 晃动代替；倒挂、倾身非转不可时按脚点旋转换算手端（《超级棒棒糖》S12 飞行转身，道具脱手）。躺倒、摔倒（rot≈1.45）时身体半宽 5u 会转到地面以下，用 `dy = −5·sin(rot)` 抬回地面。两人一起举一根道具时不转身（spinView 换视图会换手、翻披风，杆子穿脸），改成一起跳、道具自己转一圈。
- 拿道具伸向画外的目标（照乌云、照树枝）手够不着时，让道具“发射”一个东西（星星带拖尾），拍前 0.24 秒起飞、拍点帧命中。
- 放大镜：柄从镜框画到手端、长度现算，用固定长度会戳进持镜人自己的脸颊；照别人时镜片放在被照者靠持镜人那一侧的下半身，镜柄才不会横穿被照者的脸；要照“脑子里”就在他头顶画一朵思考云去照。透视镜同理，镜片上沿要低于眼睛（眼睛在 −6u）（《你瞒我瞒》）。4:3 封面里拿放大镜的人站在道具外侧（手在镜片外侧），否则镜柄会横穿她自己的帽子。
- q 视图里 R 臂画在身体后面（第 2 层），挂在 armR 上的道具会落在身后或身侧，手里的麦克风、杯子读不出来：唱歌用立麦，拥抱、张开双臂切 front 视图（《100》）。front / q 视图手臂角度超过约 1.9 rad 也会转到身体后面（第 0 层先画），双手合十、抱头都像没抬手，抱头用 1.75（《99》）。front 视图两臂都在第 0 层（画在身体和耳机、帽子之后），永远在身体两侧 ±5u 以外：举手会被耳机挡住，改用 q 视图的 L 臂（第 1 层）加手点（《东京不太热》）；够不到胸前正中，“捧着纸条哭”改成纸条放在腿上、泪滴从下巴落到纸上（《我好想你》）。q 视图的手在身体外侧 ±6–7u、高 −5 ~ −6.7u，够不到嘴：喝东西时杯子拿在手上、贴着脸侧、杯口往脸倾 0.45–0.5，别把杯子往嘴的位置插值（会落在眼睛上像单片眼镜）；够不到高处台面（从上往下倒手冲壶）就让他站在木箱上（《苦咖啡·唯一》）。“躲在手机后面偷看”这类要挡脸的道具，用世界坐标画在角色之后、盖在脸前，偷看时让角色 dx 探出半张脸。
- 秋千、吊绳：两根绳各自挂在横梁上平行摆（平行四边形），座板保持水平，人用 `seat()` 坐在座板上、不跟着转；整组绕一个支点旋转会让座板竖起来像梯子。披风（《超级棒棒糖》`lp.cape`，画在角色之前）：q 视图朝右的人 side=−1，朝左（flip）的 side=+1，`b = side`。
- 举过头顶的牌子先画、角色后画，木杆藏在身体后面；后画会让木杆一路戳到两眼之间。牌子整块在头顶之上：牌心 y ≈ 脚 y − 13.6u − 70，杆从牌底画到手端（《去北极忘记你》`bj.signUp`）；`placardSign` 直接放在手上会被身体挡住大半。
- 亲脸颊：两人中心距约 11.5u，她倾约 0.1 弧度、他回倾 0.04，顶角刚好碰上；倾斜时把表情自带的 dx 摆动清零（love 有左右晃），否则身体会压进对方。
- 影子梗用《东京不太热》`tk.silhouette(fn, col, a)`（`ColorFilters.Blend(SrcIn)` 图层把任意绘制变成纯色影子）。两人的影子牵手：地上的读不出来（贴地又被人挡住），放在头顶上方的墙上，影子位置单独定、不严格按投影；真人隔开约 170 px、胳膊垂下，只让影子的手够到一起，落拍弹心，否则像真人先牵上了。和本人牵手的影子（示例文本仅）要同尺寸、同地面线、深色约 55%：放大 1.3 倍时影子的手比真人高约 80 px，被审成“没牵到”。

**遮挡与绘制顺序**
- Clawd 的脸就在身体上：抱在胸前的书、纸会把整张脸挡住，路人捧花放身侧（《宠坏》）。坐着时膝上道具放在座面以上 1.5u 以内；抱在胸前的大道具（水晶球）放在嘴以下，底座不进歌词条。从上方掉下来的道具（拍桌的档案）从两人之间的空当里落，别从脸前划过。
- 坐着的 Clawd 用 `sets2.seat()`（硬规则 1）：身体底边落在座面上，腿垂在座面前沿。桌子、器材后面的角色先核对身体顶边和台面 y；人物正后方别正好是桌面、招牌这类横向物件：桌上的杯子像落在头上（《苦咖啡·唯一》高脚桌至少露出一半台面），招牌卡进耳机弧线像戴在头上（《东京不太热》改成卷帘门铺面）。自己画的沙发、长椅按“椅背 → 椅面前沿 → 人物 → 扶手 / 椅腿”画；先画人再画椅面前沿，腿和下半身会被吃掉。坐车、坐船时用 noLegs，但身体底边要低于车斗或船舷约 1.2u，车斗最后画，否则人浮在车上。
- 从幕布或门边探头：把角色裁在遮挡物边线外侧，不要在角色身前补画一截遮挡物，否则像卡在布里。伪装梗（纸箱、灌木）要露出识别物，例如她的粉色小脚、压在箱盖上的帽子、露出来的眼睛（《第三人称》用户原话：“31s 这处卡了身子”“第三个纸箱没明白是什么”）。《去北极忘记你》`bj.herBox` 箱底粉色小脚 + 两个眼洞 + 箱盖里露出毛线球，一眼读得出，可以每个场景藏一次、结尾揭晓。从容器里冒出来（垃圾桶）：容器要比角色宽，角色缩小，裁在桶口以上露出大半身，盖子顶在头上。
- 光束、聚光灯先画，人物后画；画在人身上会把人洗灰、透出背景线。灰→彩扩散（`hl.desat` + `clipPath(kDifference)` 圆外去色）按“景 → 去色 → 色环 → 角色”画。角色全程彩色，或和色环同在拍点帧变色（`grey = 0 if t >= B[k] else 1`，不提前渐变）；色环从拍点帧起扩，那一帧半径约 300。
- 粒子：爆心、彩纸、爱心环的中心放在角色头顶上方（《100》6 处盖脸）；下落的音符雨、彩纸先于角色画，或限制在 y < 88%（歌词条区域）。绕人转的东西（照片旋转木马）轨道放在腰腿高度、前半圈在嘴以下，放在胸口会一圈圈挡脸（《我好想你》）。
- 场景从中间裂成两半（长椅裂开、中间出星河）：先平移、再按裂缝裁剪，两半各补一道裂边；否则木条连着跨过缺口。
- 底部歌词条一直占着画面下方（水彩逻辑画布约 y 950–1080，render.py 字号 64、y=1012；p5 模板 y 975–1070；320 像素 y≈158/180）：卡点道具不放进去（茶几、印章、小物都往上挪），结尾遮罩画在歌词层之上。画面里的界面（相机 App 等）做成横屏样式、控件放右侧，别和歌词条抢位置；角标、计数徽章离手机壳内边至少 30 像素，否则被壳边裁掉。
- 气泡尾巴要指向说话的人；说话人在画外时改用思考云，引出的小圆点往画外走，别碰到桌上的道具（会像道具在说话）。印章字、拟声字避开角色这一拍跳起后的位置；跟着道具出现的印章字位置写死，别跟道具飘到别人头上。

**表情与字体**
- 水彩引擎的表情名只能用 `clawd.EMO` 里的 26 个键（love、starstruck、hopeful 等；没有 furious、sleepy、bored、disgusted、mischief）。写错不报错，会静默变成 neutral，还会眨眼（《宠坏》落拍那帧闭眼）。眼睛、嘴的样式放进覆盖 dict，如 `feel('neutral', t, dict(eyes='sleepy', mouth='yawn'))`。
- `emotions()` 换表情后约 0.14 秒内会眯眼过渡：要在拍点帧露出新表情（爱心眼、哭脸），键写在拍点前约 0.06 秒。表情自带的 emote（汗滴、！、？）还要再晚 0.06–0.32 秒才淡入，靠 emote 卡点时键写在拍点前约 0.16 秒。surprised 自带一个“!”，再叠“!!”时在覆盖里写 `emote=None`；它还自带 take = 1.3，会把身体压扁、露出身后的招牌字（换表情那几帧设 `o['take'] = 0`，sq 封顶 0.06），眼睛会换掉墨镜（要保留就覆盖 `eyes='shades'`）（《东京不太热》）。
- 谁是谁靠颜色：love 表情自带 rosy 色调，他（橙色）一 love 就偏粉，和她同框时给他用 happy 加 `{'eyes': 'heart', 'blush': .8}` 覆盖；路人别用粉色、淡紫（会被认成她），用薄荷绿、淡黄（《东京不太热》）。
- 快乐体缺 ♥ ♡ ★ ‹ → ← ↗ ⇄ ∞ ①②③④ ■ ▶ ◀ ✓ ✕ ℃，会出豆腐块（《你瞒我瞒》便利贴、《超级棒棒糖》评分星、《东京不太热》温度牌都踩过）。符号一律画：心形、返回键、箭头（路牌靠板子形状）、评分星 `starPts`、播放键、对勾（《100》`hb.playIcon` / `checkMark`）。文楷只缺 ✕，里程牌、车票、菜单、招牌、温度牌的数字和 ℃ 可以用文楷直接写。出片前用 skia `Font.unicharToGlyph` 扫一遍镜头文件里的非 ASCII 字符。
- q 视图 flip 后，`draw` 钩子里写的字（围裙上的「橘」）会镜像：钩子里按 flip 再 `scale(-1, 1)` 回来（《东西》）。

**连续性与界面**
- 跨镜动作方向要连续：上一镜往左甩、往左跑，下一镜就从右往左接。两人对视的连续镜头守轴线：上一镜他在左、她在右，下一镜不要换边。
- 角色丢掉的道具（帽子、放大镜等），后面的镜头和回扣都要同步去掉或还原。
- 扭头不理人用 'qback'（看不见脸）并朝反方向 flip；q 视图看起来仍是对着镜头生气，转身梗读不出来。
- 偷、抢、递这类动作要有接触帧：手伸进去 → 拿着出来 → 送达，道具不要瞬移。
- 界面通知各占一个槽位；“划走”要横向滑出，不要在原地淡出，也不要叠在同一处（《宠坏》）。
- 翻牌乱翻时，从字池里排除该格的目标字，免得锁定前就提前出现（《宠坏》「2026」）。

**卡点时序**
- 转场要在拍点帧之前完成，拍点帧已经是新镜头。开花、结果、雾散这类生长事件，拍点帧要已过半：`k = (t − tb + .06) / .1`。写字、撕页这类过程事件，结果在拍点帧已经可见：过程从拍点前约 0.25–0.3 秒开始（写字 `p = (t − tb + .24) / .3`；撕页旧页从拍点前 0.3 秒往上飞走、不扫过角色，落拍帧新页轻弹一下）。`props.stamp(age)` 只提前 0.035 秒、0.16 秒 backOut，拍点帧只有约 7 成大：拍点印章、大字传 `t − B[k] + .1`（《苦咖啡·唯一》`kf.bage(t, k)`）。弹出物里的字跟弹出物同时出：`k = (t − (B − .06)) / .16` 在拍点帧只有约 0.4（backOut 后已≈1），写 `if k > .5` 才画字会出“空云”，阈值用 0.2（《东京不太热》）。
- 掉落、扣上（冰袋落到头上）落点在拍点帧：`drop = clamp((t − (B[k] − .16)) / .16)`。一拍掉一片叶子、一瓣花这种“离开”，拍前 0.1–0.14 秒就开始走，否则拍点帧还挤在原位；摘花瓣要少瓣（4 瓣、一拍一瓣、最后一拍只剩花心），飞走那瓣全不透明、加速度线。纸团落篓：拍前 0.54 秒开始揉（0.14 秒揉完），0.36 秒抛物线正好在拍点帧落进篓，篓弹一下 + 「进！」。
- 水彩转场（4.1 节的 render.py 已全部实现）：cut、pop 直接用；wipe 从拍点前 0.16 秒、iris 从拍点前 0.2 秒开始，都在拍点前做完（composite 在这个窗口里就提前切到下一镜；iris 卡点也可以直接换 pop）；dissolve 是 `t0−0.04 → t0+0.25`，跨在拍上，只给不卡点的慢切换用；flash 是上一镜在拍点前 0.1 秒内渐白到 0.82（到 100% 那帧整帧只剩纸色和字幕），拍点帧切新镜头，余白 0.22 在 0.12 秒内褪掉。
- 自己改 render.py 时别丢这两处（4.1 节版本已有）：① `drawShot` 用 `getSaveCount/restoreToCount`、`Renderer.frame` 开头 `restoreToCount(1)`：镜头里 `cam()` 只 push 不配 `camEnd()` 会每帧漏一层 save，第一个转场起整片冻在一条缝里、字幕消失（《白山茶》）。② 帧末采样余量用 `1e-5`：`1e-3` 会让落在帧末 1 毫秒内的拍点晚一帧。
- 像素 320 的 tear（6 帧）、glitch（3 帧）从镜头起点才开始（`render.py` 里 `dt ≥ 0`）。引擎整体画面虽已比音频提前 2 帧（`LEAD`），镜头起点放在拍点上时，拍点帧还在撕、还在花：卡点时把这类镜头的起点写在拍点前约 5 帧（tear）/ 2 帧（glitch），再用逐拍帧条确认拍点帧已是新镜头。
- 卡拉 OK 相邻两句间隔小于 0.45 秒时，新句固定满尺寸硬切（`pop_ = 1`）：原版的缩放弹入会让换行那一帧新句很小或字距发散。说唱句常在小节线后 0.15–0.3 秒才开口，镜头切在小节线上时切镜帧还挂着上一句（被审成“歌词慢一拍”）：句首前 0.45 秒内有切镜，就在切镜那帧换上整句（未唱的字奶白，逐字变色仍跟人声），上一句同时收掉（《99》`_cutBefore`）。
- 镜头第一拍就是“状态突变”（指针回零、灯灭）时，本镜第一帧已是结果，在拍点帧补残影 / 速度线把变化过程画出来。滑入、挤进画面这类“赶在拍上到位”的动作也一样：拍前那段在上一镜里看不见，放进转场窗口（wipe 的拍前 0.16 秒内）或改成拍上弹跳（《你瞒我瞒》大头贴挤进画面、大头贴滑进档案袋）。
- 闪烁的东西（报警灯、最后一格血条）按拍点定相位：`frac((t − tb + .04) · f) < .5` 为亮，否则落拍那帧可能正好是灭的。场内闪光灯的峰值用 `after(t, k, lead≈0)`，默认 lead 0.04 会早一帧整屏发白；落拍白闪从 `t − B[k] ≥ 0` 起。全屏闪光、压暗放在 `camEnd()` 之后画，写在 `cam()` 里只盖住镜头变换后那一块，平移后出一条硬边。
- 镜头切换和快门、闪光事件不要叠在同一拍：转场本身有白闪时，那一拍只做对焦锁定这类轻事件，快门放下一拍（三样叠在一拍会把人整个挡住）。
- 收尾截在重拍上时，落拍那一下的全屏白闪要弱（约 0.32，0.1 秒褪完），淡黑缩到约 0.14 秒，否则收尾画面清楚的时间不到 0.15 秒。音频自带淡出时，结尾 `FADE = (DUR − 0.5, DUR − 0.04)` 淡到 100% 黑；最后一拍是收尾大事件时缩到 `(DUR − 0.3, DUR − 0.04)`，0.5 秒会把最后一拍吃掉（《去北极忘记你》）；慢歌完整版尾奏余音长，末尾约 2.5 秒淡到全黑（《我好想你》）。
