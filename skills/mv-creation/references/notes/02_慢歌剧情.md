# 慢歌：先写剧情主线（原 3.1 节，用户 2026-11-03 定）

> 这是 mv-creation 技能的分层资料，原样从技能主文件移来（2026-11-04）。文中「x 节」「硬规则 N」指主文件同名小节；原 3.1 节在 references/notes/02_慢歌剧情.md，4.3 节在 references/notes/03_写镜头代码.md，4.6 节在 references/notes/05_竖屏2x3.md。维护时在当前仓库中更新对应文件，由版本控制记录改动。


用户原话：「慢歌应该是有一个剧情主线故事的（快歌像我们这样做没问题）」。《于是》《后来》《我好想你》都是一句歌词一个独立小画面，镜头之间不接剧情；用户给的像素剧情版《我好想你》镜头长度和我们差不多（中位约 6 秒），差别在镜头之间是一条因果链。快歌照旧（一句一镜一梗，要求卡点再加每拍一事件）。

1. **一句话故事 + 钩子问题**：前 3 秒用旁白抛出问题（参考片：「对面那盏灯 闪了四下／我用了十六年才看懂」），高潮回答；最好歌名就是答案（四下 = 「我好想你」四个字，落在唱这句的时候）。片段任务（不是整首）也要有一条小因果链：开头抛出、结尾回答。
2. **一个故事装置**：简单、看得见、能重复、能计数的暗号或物件（灯语：一下晚安、两下明天见、三下楼顶见）。前半段埋，后半段揭；埋下的东西全部回收（参考片：传零食的木板、满墙正字、纸条、开头的小卖部老板）。
3. **段落分工（完整版）**：

   | 段落 | 讲什么 |
   |---|---|
   | 前奏 | 钩子 + 片名 + 主角在“现在”出场 |
   | 主歌 1 | 现在的处境（孤独、年份翻页、未读消息） |
   | 副歌 1 | 回忆主线，留下谜 |
   | 间奏 | 现在的行动与发现，揭晓谜底 |
   | 主歌 2 | 同一段时间换另一人的视角，补全真相 |
   | 副歌 2 | 高潮：歌名那句 = 装置的答案，再给回应或反转 |
   | 尾奏 | 结局（参考片：「十六年后的第一个明天」）；不出片名（硬规则 8） |

4. **双时间线**：现在 / 过去用光色区分（冷色雨夜 vs 暖色台灯），角落标年份季节（「2003 · 秋」）；人物首次出场打名字卡（「林光 · 34岁 回来住最后一晚」）。
5. **旁白字幕**（慢歌完整版默认加，用户 2026-11-03 确认）：第一人称短句，一屏一句、约 12 字以内，顶部居中，约 5 秒一句（参考片 5 分钟约 55 句）；歌词仍在底部，开头和片名错开位置。旁白讲故事，歌词按意思落成具体剧情细节（「踮着脚」= 她够不着窗、每次都踮脚；「示例文本仅」= 我没下楼，假装已经睡了），也可以反着用（唱「偌大的房」，旁白「这张床原来这么小」）；同一句歌词唱两遍时对两个不同的剧情点。水彩用文楷，像素 640 用 Unifont。
6. **场景经济**：一个主场景贯穿多年（同构图换年代、年龄、光色、道具），加 3–5 个副场景；聊天、新闻这类界面做中段交代（「十六年 一条也没读」的未读消息、拆迁新闻）。换视角时复用布景：她的房间 = 他的房间整体镜像（roomBack 里 `translate(W, 0) scale(-1, 1)`，挂历等带字物件放在镜像外按 `X(x)` 画），镜头函数加 `who` 参数（《我好想你》主歌 2）。
7. **节奏**：一个剧情点约一句歌词（4–8 秒），镜头之间要有因果；靠镜头内运动和光变推进，不靠快切。
8. **先写一页故事再分镜**：一句话故事、钩子问题和答案、装置、埋设 / 回收清单、段落 → 剧情点表，写在分镜数据文件开头，交付消息里附上（按硬规则 7 不停下来等批准）。交付前自查：只看画面和旁白能不能讲出这个故事；每个埋下的东西有没有回收；钩子在高潮有没有回答。
9. **开头要让人留下（《匆匆那年》2026-11-03，用户原话：「开头的桌面还需要能吸引人一点 补充更多的细节 让我看到就必须要留下来看」「读书时期桌面上都会写满的 基本上没有空地方」「黑板细节也可以再丰富一点」）**：
   - 第一帧就是满画面，不从黑场淡入；钩子问题的旁白 0 秒就出现，第二句用具体数字制造反差（「我欠他99次 他只欠我1次」）。
   - 主场景器物要写满：故事字迹不透明、醒目，四周再铺一层半透明、不同颜色的年代涂鸦（公式、「早」、井字棋、到此一游、互怼「过线的是猪 / ←你才是」），只给故事元素留位置；黑板写励志语录和值日名字，结尾值日表回扣成男女主的名字。
   - 安静前奏里让现在的场景自己回放：半透明暖金色的旧物滑过、每次触发装置计数一下；新声部（弦乐）进来时装置逐组发光。前奏里顺手埋下后面要回收的人或物（同学会名牌：他也会来）。
   - 用户要先看开头时，先只渲前奏到第一句（约 28 秒）给他审，他会边看边加细节，定了再做全片。
10. **装置与场景**：选能写字、能计数、俯拍看得清的器物（三八线 + 两边的「正」字账，修正液涂白、只留一笔）；同一俯拍构图跨十年叠化（过去那一笔 → 十年后同一笔）最省也最有力。开工前看前几首慢歌用过的装置，别重复（铁盒纸条《我好想你》、日记天台《后来》）。
11. **旁白细节**：顶部一句加柔和暗底条；双视角时句首加说话人标记（她粉圆点、他橙方块），角标写「同一年 · 他的座位」。旁白不和画内文字（粉笔字、桌面字）同屏同位置：调镜头取景或挪画内字，不挪旁白。
12. **Clawd 慢歌造型与教室**：围巾在 Clawd 身上落在身体中段像腰带，冬装改毛线帽 + 积雪；少年用 `hl.her17` / `him17` 加暖色，现在用冷蓝加年份角标。讲台视角的教室：桌面只画薄板 + 细腿（不画前挡板），两人用 `seat()` 坐，桌面横过身体中下部、腿从桌下露出；后排同学缩小抬高（u 22、座面高 160 px）才有纵深，镜头 z≈1.3 对准两人。
13. **改名与成本**：用户可能中途改名（《匆匆那年》改成方茴 / 陈寻）：名字只放在名牌、名字卡、信封、信、值日表这些画内字上，grep 一遍替换，再用 `build_strokes.py --merge` 补笔顺。4:01、44 镜实测（2 核）：720p 预览约 15 分钟；2K 约 1.1 s/帧/进程、约 55 分钟（9 轮前台 480 s），母版 437 MB（25 MB × 17 片）。慢歌自审：从预览每镜抽 2 帧（35% / 82%）拼两张图，一次看完全片。
14. **竖屏说唱慢歌（《罗生门》4:04、53 镜，2026-11-04）**：前奏 30 s 用 B 式聊天序幕 + 0 秒旁白钩子（界面放进手机 `inPhone`，顶部留给旁白），用户一次通过。装置从歌词里找：「示例文本仅供演示示例」→ 两地天气小黑板 + 每晚同一句问天气，◀◀ 回放每屏都是这一句。说唱主歌两三句一镜（3.5–5.5 s），手机界面（打字删光、撤回、购票、备忘录、通知涌入、语音转文字）占三分之一。她的房间 = 他房间函数 `who='her'`。
15. **后半段不能比开头简陋**（用户：「后面就开始变得敷衍了」）：复用十几镜的布景要换机位、换光（清晨 / 中午光带浮尘 / 黄昏 / 夜灯）、加小剧情；每个场景铺一层烟火气（主文件 3 节）。配角可以只用痕迹出场（门缝暖光、探头的猫、夜里披上的毯子、「先用着 —301」纸条），比名字卡自然。加了细节层后 2K 约 0.9–1.3 s/帧/进程（4:04 约 60 分钟）。
