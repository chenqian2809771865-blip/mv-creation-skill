# 画风实现备忘

这些是按画风选用的实现经验，可根据参考、歌曲和用户要求调整。

## 像素

- 全片使用一致像素格；例如 320×180 再最近邻放大。近景优先增加精灵像素细节，避免局部放大后像素尺寸与背景、文字不一致。
- 有参考驱动的项目，先读取按 [多参考综合](references/multi-reference.md) 形成的项目规范，再确定网格、轮廓、光照和动画节奏。素材与合成遵循同一规范；参考中实际存在的混合风格要记录为具体例外，不自行把它简化成统一的“8-bit”。
- 小色板有助统一画面，但不把颜色数量设为固定上限。抖动按需要使用，检查压缩后的纹理。
- 像素文字和画面在同一网格渲染，PIL 可设 `fontmode='1'`。字体选择以参考和中文覆盖为准。
- 设备界面、HUD、血条和存档元素只在故事需要时加入。
- 发抖音、在意画质时优先用 640×360 引擎（`assets/engines/pixel-640/`），它的抖音画质规则见该目录 README：不整帧抖动、粒子 12fps 步进、光晕分阶平涂、镜头整数像素平移。

### 320×180 参考驱动项目的已验证做法

- 回忆段：背景直接用暖色板画亮底，人物保留原色，整帧向暖色阶拉约 35–40%；整帧压成单色暖调会让人物和墙同色。
- 冻结/离别段：按亮度吸附到 7 档冰蓝平涂、不抖动，只留信物红；先做冰蓝再压暗，红色物件在压暗之后画。
- 世界替换：竖条撕裂约 6 帧；进回忆配 ◀◀x8、跟踪噪条和日期戳，快进用 ▶▶x8 每拍换格。
- 近景用 160×90 区域整数 2×，手高 ≥24px、多边形平涂加 1px 轮廓。浅色背景上的气泡加 1px 深边；正文 Unifont 16px，时间戳 12px。
- 弹窗背后用平涂乘色压暗（约 ×0.4），不用抖动；缩略图用原像素裁切，不隔点抽样。
- 镜头内光色变化只对背景做有序抖动混合；雨大到看不见人：平涂混灰蓝（≤0.6）＋更密粗雨丝，人物抖动透明度消失。
- 闪电：1 帧近白（236,242,255），之后光照乘色约 0.22–0.3 秒指数回落，暗处粉笔字跟着提亮。
- 像素卡拉 OK：淡入淡出约 0.1 秒（抖动透明度拉长会碎）；中文用 Unifont 16px，小标签用 Fusion Pixel 12px（`scripts/get_fonts.py --unifont --fp12`，PIL `fontmode='1'`）。整句超过画面约 94% 时拆两半翻页，SRT 仍按整句。
- 联系表自检：人物与背景同色、字幕出界、气泡被吃掉、特写主体太小、画面里的字被头挡住或被底边截掉（浅地面粉笔字加 1px 深影）。

## 矢量、笔刷与纸感

- 模板的水彩外观由 p5.brush 与纸纹合成；若改成像素或其他画风，重新选择绘图实现，复用角色定义和动作思路。
- Skia 与 ffmpeg 传输保持像素格式一致；使用随附分段脚本时输出 BGRA，避免逐帧额外转换。
- 纹理、雾和颗粒可缓存或低分辨率合成；先测帧耗时，再针对瓶颈优化。兼容问题以当前系统实测为准。
- Skia 水彩引擎的经验：不要逐形状 `makeShader`（每次约 140ms），纸纹颗粒做整帧预生成图；自定义配色要把 col/dk/lt 传进 `emotions()`；浅底光晕用 screen 混合；版式按 1920×1080 写再整体缩放；角色避开底部歌词条。
- skia-python 的实测经验（87.7 版；2026-10-29 用 144.1 版跑随附引擎正常）：
  - 全屏贴图在带旋转的矩阵下画，约慢 25 倍。画贴图时去掉旋转，只留缩放和平移。
  - 水彩层用普通合成；Multiply 混合的 `saveLayer` 每层约多 0.12 秒。
  - 在 aarch64 上，透明度小于 1 的图片要用 `saveLayer` 包住再画，否则透明度可能失效。

## 中文、手写字

- 字体按画风和可读性选择，用 fontTools 或测试帧检查实际用字覆盖。字体需随工程合法分发时一并保留许可。
- 从 GitHub 下载字体等原始文件时，用 `raw.githubusercontent.com` 的地址；`github.com/.../raw/...` 链接经代理可能返回 403。
- 真实笔顺可以使用 `scripts/hanzi.py`（依赖 numpy、Skia）。笔画数据用 `scripts/build_strokes.py lyrics.json --out strokes.json` 只提取本歌用到的字；`hanzi.py` 首次用到时才读取（同目录或 `MV_STROKES`）。
- `write_char(canvas, 字, x, y, size, progress, paints)` 按 0–1 进度绘制。字级节奏按表演需要调整，描边先画、墨迹后画，避免后笔描边遮住前笔。
- 字幕的字号、位置和底板以目标设备上能读清为准，不固定一种字体或歌词框。
